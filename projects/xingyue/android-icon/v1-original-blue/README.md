# 星阅 · Android Logo · v1 原版蓝色

这是你确定采用的蓝色纸页 Logo。

## 下载

**[完整素材包 ZIP](XingYue-Android-Delivery.zip)**（包含 38 个文件）。

解压后：

- `01_approved_original/`：原版蓝色高清 PNG，建议优先用于视觉还原；
- `02_editable_svg/`：SVG 矢量复刻版本，非原版逐像素源文件；
- `03_android_adaptive/android-res/`：Android 自适应图标、mipmap 各密度 PNG 和 XML；
- `04_previews/`：效果预览；
- `README_安装说明.txt`：安装步骤。

## Android 使用

合并 `03_android_adaptive/android-res/` 内的资源到 Android 模块的 `app/src/main/res/`，在 `AndroidManifest.xml` 的 `<application>` 中使用 `android:icon="@mipmap/ic_launcher"` 与 `android:roundIcon="@mipmap/ic_launcher_round"`。覆盖前备份原图标资源。

后续版本另建 v2，不覆盖 v1 原版蓝色。
